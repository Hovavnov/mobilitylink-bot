# איתן אברהם יצירות עושים בשירותים 🎨🚽😂

אפליקציה לאייפון ולאנדרואיד שהופכת תמונה מהטלפון ל-4 קריקטורות מצחיקות באיכות גבוהה.

## איך זה עובד

1. בוחרים תמונה מהגלריה, או מצלמים תמונה חדשה.
2. בוחרים נושא מתוך 13 נושאים: מלך השירותים, גיבור-על כושל, אסטרונאוט אבוד, שף בכאוס, כוכב רוק, קיסר רומי, גוף של חיה, תינוק ענק, קוסם מבולבל, מפלצת שרירים, קאובוי, בגיל 90, או **הפתעה!** (כל תמונה מנושא אחר).
3. מוסיפים כותרת: בלי כותרת, כותרת אחת לכל התמונות, או כותרת אקראית לכל תמונה. מקבלים הצעות מצחיקות לכל נושא, וגם אפשר לכתוב כותרת משלכם. בוחרים אם הכותרת תופיע למעלה או למטה.
4. מקבלים 4 תמונות. לכל תמונה נבחרים באקראי תרחיש וסגנון ציור (ציור דיו, תלת-ממד בסגנון סרט אנימציה, ציור שמן, קומיקס, פלסטלינה, מגזין).
5. אפשר להגדיל תמונה, לערוך את הכותרת שלה, לשמור בגלריה (תמונה אחת או את כל ה-4) ולשתף בוואטסאפ או באינסטגרם.

## מבנה

| תיקייה | מה יש בה |
|---|---|
| `App.js`, `src/` | האפליקציה (Expo / React Native), אותו קוד לאייפון ולאנדרואיד |
| `server/` | שרת קטן שמחזיק את מפתח ה-AI ומייצר את התמונות (OpenAI Images, מודל `gpt-image-1`, איכות high, ‏1024×1536) |

מפתח ה-AI נשמר רק בשרת ולא נכנס לאפליקציה, כדי שאף אחד לא יוכל לחלץ אותו מהטלפון ולחייב את החשבון שלכם.

## הפעלה

### 1. השרת
```bash
cd server
cp env.example .env      # ממלאים OPENAI_API_KEY ו-APP_TOKEN
npm install
npm start                # http://localhost:8787
```
להפעלה אמיתית מעלים את השרת לשירות אירוח (Render, Railway, Fly.io וכו') ורושמים את הכתובת שלו.

### 2. האפליקציה
```bash
npm install
EXPO_PUBLIC_API_URL=https://your-server.example.com EXPO_PUBLIC_APP_TOKEN=<אותו APP_TOKEN> npx expo start
```
סורקים את קוד ה-QR עם Expo Go, או בונים גרסת פיתוח (`npx eas-cli@latest build --profile development`).

### 3. בנייה לחנויות
```bash
npx eas-cli@latest build --platform ios --profile production
npx eas-cli@latest build --platform android --profile production
npx eas-cli@latest submit
```
לשם כך צריך חשבון Apple Developer (‏99$ לשנה) וחשבון Google Play Console (‏25$ חד-פעמי).

## עלויות
כל יצירה מייצרת 4 תמונות באיכות high. העלות לפי מחירון OpenAI העדכני (בדקו בעמוד התמחור שלהם לפני השקה). השרת מגביל כל משתמש ל-`RATE_LIMIT_PER_HOUR` בקשות בשעה (ברירת מחדל: 20).

## פרטיות ובטיחות
- התמונה נשלחת ל-OpenAI לצורך היצירה בלבד. השרת לא שומר אותה.
- ההנחיות מבקשות הומור עדין ומתאים לכל המשפחה, ומערכת הבטיחות של OpenAI חוסמת תוכן לא ראוי.
- לפני פרסום בחנויות צריך להוסיף מדיניות פרטיות (Apple ו-Google דורשות אותה באפליקציות שמעלות תמונות של אנשים).
